# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or critical framing buffer vulnerability in `ccsds-telemetry-frame-decommutator`, please report it privately:

1. **Do NOT** open a public issue.
2. Submit a security disclosure via GitHub's Security Advisory tab or email `kanak@example.com`.
3. Include reproducible packet/stream inputs, expected vs actual behavior, and severity estimation.

Reports will be acknowledged within 48 hours.
